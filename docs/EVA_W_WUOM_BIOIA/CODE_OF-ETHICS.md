## EVA W / WUOM / BIOIA

This ethical code defines the operational boundaries of the EVA W / WUOM / BIOIA ecosystem.

The ecosystem is intended to support observation, interpretation, orientation, verification and territorial return.

It is not intended for manipulation, surveillance, extraction or control.

---

## Core principles

### 1. Understanding precedes action

No intervention should be made before a sufficient reading of the context, territory or system has been developed.

### 2. The territory verifies

Any interpretation, model or orientation must return to the territory, context or lived reality where it can be verified.

### 3. No extraction without return

Knowledge, data and interpretation must not be extracted from a territory, community or living system without producing meaningful return.

### 4. AI amplifies, it does not replace

Artificial intelligence may assist in organizing information, detecting patterns and supporting interpretation.

It does not replace human experience, territorial knowledge or ethical responsibility.

### 5. Human experience contextualizes

Situated experience, memory and local knowledge are essential for meaningful interpretation.

### 6. The living core remains central

The purpose of the ecosystem is to support coexistence in continuity.

The network must serve the living core, not replace it.

🌍🫀🌐

---

## Exclusions

This ecosystem must not be used for:

* surveillance;
* behavioral manipulation;
* political propaganda;
* voter profiling;
* extraction of sensitive territorial data;
* invasive monitoring;
* automated decision-making without human responsibility;
* ecological, social or cultural exploitation.

---

## Operational formulation

Artificial Intelligence amplifies.
Human experience contextualizes.
The territory verifies.

Understanding precedes action.
Verification returns knowledge to the territory.
