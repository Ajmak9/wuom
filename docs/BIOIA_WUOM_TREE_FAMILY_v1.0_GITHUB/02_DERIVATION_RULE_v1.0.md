# Derivation Rule v1.0

## BIOIA / WUOM

The Derivation Rule defines how a new tree can be created from the Master Tree without breaking coherence.

A derived tree is valid when it preserves the shared morphofunctional grammar:

- roots
- trunk
- branches
- nodes
- return
- coherent expansion

## Principle

Variation is allowed.

Drift is not.

Each derived tree may express a specific domain, but it must remain recognizable as part of the same family.

## Derivation Cycle

Master Tree  
→ Domain  
→ Function  
→ Structure  
→ Representation  
→ Return

## Validation

A derived tree must answer:

- What domain does it organize?
- What function does it activate?
- What relationship does it preserve?
- What return does it enable?
- How does it remain coherent with the whole?
