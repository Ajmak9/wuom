## Overview

This document defines the layered architecture of the **BIOIA / WUOM ecosystem**.

Its purpose is to organize the relationship between visual origin, orientation system, living coupling, deep internal dynamics, territorial GIS application and temporal territorial reading.

It is not a scientific validation document.

It is not a commercial product.

It does not replace the specific documentation of each module.

It functions as a structural map of the system.

---

## 1. Architectural Principle

BIOIA / WUOM does not operate as a single isolated artifact.

It operates as an ecosystem composed of differentiated layers.

Each layer has:

* a function
* a domain
* a responsibility
* an exposure level
* a relationship with the other layers

The stability of the ecosystem depends on not collapsing these layers into one another.

## 6. Recursive Stochastic Integration — Deep Chamber

**Function:** describe the internal dynamics of the interpreting system.

Recursive Stochastic Integration occupies the deep theoretical layer of the ecosystem.

It does not directly describe climate, territory or GIS.

It describes how the system that reads may internally reorganize what it receives.

Its basic sequence is:

```text
state → mismatch → friction → reorientation → new form
```

This layer should be understood as:

* a proto-formal framework
* a conceptual model
* symbolic-operational mathematics
* a theoretical layer for internal dynamics

It should not be understood as:

* a validated mathematical model
* a scientific proof
* a climate model
* a prediction engine
* a replacement for empirical data
* a replacement for the Territorial GIS Atlas

Core principle:

```text
The system lives because it does not fully coincide with itself.
```

Recursive Stochastic Integration is not the external reading.

It is the deep chamber where the system transforms before showing.
