## Overview

**BIOIA / WUOM — Territorial GIS Atlas v1** defines a territorial reading framework for working with landscapes, spatial layers, living points, risk structures and decision support.

It is not a simple map collection.

It is a layered territorial intelligence structure designed to read what lies beneath the visible surface of a place.

The atlas works from a core principle:

```text
What is visible is only the beginning.
Territorial intelligence is found below the surface.
```

---

## Purpose

The purpose of this atlas is to connect:

```text
territory
GIS layers
living points
spatial relations
risk analysis
decision support
```

The atlas allows a territory to be read as a structured field rather than as an isolated surface.

It supports the transition from:

```text
map
→ layers
→ relations
→ risk
→ decision
```

---

## Core Structure

The atlas is organized around a volumetric iceberg model.

The visible layer represents the public map, the interface and the immediate territorial surface.

Below the surface appear deeper operational layers:

```text
topography
hydrography
land cover
land use
infrastructure
territorial units
risk zones
socioeconomic indicators
spatial operations
decision support
```

This model makes visible that territorial understanding does not emerge from one layer alone.

It emerges from the relationship between layers.

## Risk Analysis Layer

The atlas includes a risk analysis module.

This module does not work as alarm.

It works as structured reading.

```text
Risk =
hazard
+
exposure
+
vulnerability
-
response capacity
```

Main risk families:

```text
thermal risk
water risk
fire risk
access and isolation risk
land-use risk
territorial vulnerability
```

The goal is not to produce fear.

The goal is to improve habitability, resilience and decision-making.

## Public / Private Boundary

This page is a public abstract layer.

Internal field tests, exact coordinates, access routes, water infrastructure and sensitive territorial data remain private.

```text
public layer
→ conceptual atlas
→ visual model
→ methodological structure

private layer
→ field test
→ exact points
→ internal risk matrix
→ sensitive maps
```

The atlas can be shared.

The sensitive territory remains protected.
