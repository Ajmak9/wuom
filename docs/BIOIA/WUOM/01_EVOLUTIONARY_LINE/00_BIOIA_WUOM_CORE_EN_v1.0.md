# 01 · BIOIA / WUOM CORE

## Reading · Orientation · Return

### Status

**Constitutive document**  
**Version:** v1.0

---

## Purpose

This document defines the operative core of BIOIA / WUOM.

The core is not an application, an interface, or a methodology.

It is the structural intention that organises the system:

> **to read, to orient, and to return.**

---

## Core

BIOIA / WUOM is organised around three fundamental movements:

1. **Reading**  
   Understanding the relationships present within a living system.

2. **Orientation**  
   Transforming that reading into situated criteria.

3. **Return**  
   Returning knowledge, learning, or value to the territory from which it emerged.

---

## Central principle

> **Every reading must be oriented.  
> Every orientation must return.**

---

## Function within the system

The BIOIA / WUOM core:

- organises the system's general meaning;
- articulates the relationship between territory, experience, and AI;
- supports the Cognitive Architecture;
- gives meaning to the principles;
- orients the Tree Family;
- feeds the interfaces;
- and requires territorial return.

---

## Fundamental movement

```text
Territory
   ↓
Reading
   ↓
Orientation
   ↓
Return
   ↓
Territory
```

The system does not end with interpretation.

The cycle is completed when orientation returns to the territory.

---

## Relationship with the Cognitive Architecture

The Cognitive Architecture develops how this core is internally organised.

The core defines the movement.

The architecture defines the organisation.

---

## Relationship with the Law of Territorial Return

The Law of Territorial Return establishes the structural condition that prevents reading from ending in extraction.

Without return, the core remains incomplete.

---

## Relationship with the Master Plan

The Master Plan represents the stable form of the system.

The core defines its intention:

> **reading, orientation, and return.**

---

## Closing statement

BIOIA / WUOM does not begin with the accumulation of information.

It begins with a living relationship between territory, reading, orientation, and return.

The core no longer needs to grow for the system to evolve.

> **Without custody, there is no publication.**
>
> **Without return, there is no orientation.**
