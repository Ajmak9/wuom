# BIOIA · Organization of Living Systems

**Version:** v0.1  
**Status:** Initial formulation  
**Location:** BIOIA / WUOM Metaarchitecture

---

## Purpose

BIOIA does not organize only information, data or disciplines.

Its purpose is to organize the relations that make it possible to orient living systems before intervening in them.

The architecture does not replace existing knowledge.

It connects it.

Its objective is to increase the system's capacity for orientation.

---

## The Transition

BIOIA has so far been developed primarily from the territory.

However, the same architecture can be applied to other complex systems without altering its fundamental principles.

The territory ceases to be only the object of study and becomes the first system in which the architecture is verified.

---

## What Does BIOIA Organize?

BIOIA does not organize people.

It does not organize departments.

It does not organize hierarchies.

It does not organize only data.

BIOIA organizes relations among components that form part of the same system.

These relations make it possible to construct orientation before decision.

---

## Permanent Components

Every system observed through BIOIA contains, in different proportions:

- context;
- people;
- experience;
- data;
- artificial intelligence;
- knowledge domains;
- relations;
- orientation;
- return.

The components remain.

What changes is the system in which they are applied.

---

## Domains

Domains depend on the system.

Examples:

- water;
- soil;
- biodiversity;
- temperature;
- energy;
- community;
- economy;
- health;
- governance;
- infrastructure.

BIOIA trees constitute reading domains that can be combined with one another.

---

## The Role of Artificial Intelligence

Artificial intelligence does not direct the system.

Artificial intelligence amplifies reading capacity.

It integrates information.

It detects relations.

It generates hypotheses.

Decision remains with the human system and its context.

---

## Return

Every orientation must return to the system that originated it.

Without return, there is only extraction of information.

With return, learning appears.

The system can correct itself.

It can adapt.

It can evolve.

---

## Applications

The same architecture can be used to orient:

- a territory;
- a municipality;
- an organization;
- a watershed;
- a food system;
- a restoration project;
- a scientific network;
- a public policy.

The architecture remains.

Only the observed system changes.

---

## Principle

BIOIA does not organize resources.

BIOIA organizes relations.

Orientation emerges when relations can be understood before action is taken.

---

## Relationship with the Metaarchitecture

This document expands the BIOIA / WUOM Metaarchitecture.

It does not constitute an independent framework.

It represents an emerging capacity of the architecture:

> **organizing living systems through relations, orientation and return.**
