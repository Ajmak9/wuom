## Purpose

This document introduces the metaarchitectural layer of BIOIA / WUOM.

Metaarchitecture does not replace operational architecture or methodology. It preserves the order, limits, custody and return that allow architectures, cases, interfaces and institutional relationships to evolve without losing coherence or territorial verification.

```text
Architecture
-> organizes components and relations

Methodology
-> organizes operations

Metaarchitecture
-> preserves order, limits, custody and return
```

---

## Core Distinction

The Operational Architecture explains **how the ecosystem functions**.

The Ecosystemic Governance Model explains **how coherence is preserved while the ecosystem evolves**.

```text
Architecture organizes.
Governance preserves.
Return verifies.
```

## Metaarchitectural Principles

- Orientation precedes action.
- Governance precedes expansion.
- Function defines the channel.
- Validation precedes independence.
- Custody preserves coherence before distribution.
- Artificial intelligence supports reading but does not define purpose.
- Territory remains present throughout the cycle and verifies consequences.
- Return is part of the architecture, not a later compensation.
- Non-intervention, pause, reduction of scale or withdrawal may be valid outcomes.
