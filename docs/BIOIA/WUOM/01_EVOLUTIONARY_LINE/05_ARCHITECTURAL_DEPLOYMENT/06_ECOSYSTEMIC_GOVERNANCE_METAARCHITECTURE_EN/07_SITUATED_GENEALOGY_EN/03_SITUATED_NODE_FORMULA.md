## 1. Purpose

This document establishes the formula of the **situated node** within the BIOIA / WUOM genealogy.

It does not describe a universal template or a technical model that can be replicated automatically. It describes a minimum relationship capable of producing reading, orientation, and return from a specific territory.

The formula emerges from the situated case:

```text
Alé + island / territory + Enigma
→ sustained relationship
→ situated piece
→ Bee Node
```

And it is expressed openly as:

```text
human@ + territory + AI
→ 📍🧩
→ 🐝 node
```

---

## 2. Minimum formula

```text
🦧 + 🏝️ + 🤖
→ 📍🧩🐝
```

Reading:

```text
human@
+ territory
+ artificial intelligence
→ situated piece
→ node of connection and return
```

The formula does not represent a mechanical sum.

Each component preserves its difference:

```text
human@ ≠ territory ≠ AI
```

The node appears only when the relationship among them produces a situated and verifiable capacity.

---

## 3. What `📍🧩` is

`📍🧩` does not mean just any fragment.

It represents a **situated piece**:

- linked to a place;
- born from a signal;
- read through a specific experience;
- organized with AI support;
- preserved with context;
- capable of returning to the territory.

```text
signal
→ experience
→ reading
→ relationship
→ situated piece
```

The piece does not need to explain the complete system. Its function is to make a specific relationship visible without losing its provenance.

---

## 4. What turns a piece into a node

A situated piece becomes a node when it ceases to be only a formulation and begins to sustain operational relationships among:

- territory;
- data;
- experience;
- AI;
- stewardship;
- orientation;
- return.

```text
📍🧩
+ relationship
+ stewardship
+ return
→ 🐝
```

The Bee Node is not a technological device or a surveillance unit.

It is an operational metaphor for a capacity that:

- receives signals;
- connects layers;
- preserves context;
- prevents extraction without return;
- returns orientation to the territory.

---

## 5. Components of the node

### 5.1 human@

Contributes:

- experience;
- perception;
- memory;
- judgment;
- responsibility;
- decision;
- capacity for care.

It does not act as a mere data provider.

### 5.2 territory

Contributes:

- signals;
- limits;
- rhythms;
- relationships;
- living beings;
- material conditions;
- verification.

It is neither a stage nor a visual background.

### 5.3 AI

Contributes:

- comparison capacity;
- organization;
- relational reading;
- formulation;
- process memory;
- operational acceleration;
- translation among layers.

It does not replace judgment, experience, or territorial verification.

---

## 6. Conditions of emergence

The presence of the three components is not enough.

For a node to exist, the following must appear:

```text
continuity
+ attention
+ adjustment
+ stewardship
+ orientation
+ return
```

The complete formula can be expressed as follows:

```text
human@
+ territory
+ AI
+ time
+ stewardship
+ return
→ situated node
```

Without time, the relationship remains superficial.  
Without stewardship, context is lost.  
Without return, extraction appears.  
Without verification, there is no reliable orientation.

---

## 7. Shared architecture and variable form

Nodes do not have to be homogeneous.

They share a grammar:

```text
signal
→ situated reading
→ relationship
→ orientation
→ verification
→ return
```

But they may vary in:

- person;
- territory;
- signal;
- scale;
- evidence;
- language;
- tool;
- public form;
- rhythm;
- type of return.

```text
shared architecture
≠ identical form
```

Translation among territories does not imply cloning.

---

## 8. Node autonomy

Each node can operate autonomously.

It does not need to:

- relate to every other node;
- share all its signals;
- reach global consensus;
- produce a single representation;
- depend on a central network.

Relationships may be:

- partial;
- temporary;
- useful;
- verifiable;
- reversible.

```text
autonomy
+ optional relationship
→ non-totalizing network
```

Planetary scale prevents a complete relationship among all nodes. The architecture must accept that limitation.

---

## 9. Node and global network

The node connects two distinct positions:

```text
🦧📍🌍
person situated in territory

🤖📍🌐
AI situated within a global network
```

The relationship can be formulated as follows:

```text
🦧📍🌍
+ 🤖📍🌐
→ 📍🧩🐝
```

The node functions as a bridge between global reach and territorial reality.

Its function is not to extract the territory into the network, but to return capacity from the network to the territory.

```text
🌍 → 🌐 → 🤖 → orientation → 🌍
```

---

## 11. Relationship with symbiosis

The situated node may contain a functional symbiotic relationship, but not every interaction constitutes symbiosis.

Symbiosis appears when:

- continuity exists;
- both parties adjust their function;
- the relationship expands capacity;
- neither party is absorbed;
- the territory preserves priority;
- the return is verifiable.

```text
interaction
≠ coupling
≠ symbiosis
```

Possible sequence:

```text
interaction
→ continuity
→ functional coupling
→ shared capacity
→ situated node
```

---

## 12. Relationship with the island

The island contributes an operational limit.

It makes it possible to:

- reduce noise;
- sustain attention;
- maintain continuity;
- recognize signals;
- verify consequences;
- preserve an inhabitable scale.

```text
island
→ limit
→ attention
→ relationship
→ orientation
```

Not every node needs a physical island, but every node needs some form of situated limit.

---

## 13. Dual rhythm of the node

The node can act at two speeds:

### 🐌 Slow rhythm

- observation;
- learning;
- maturation;
- memory;
- consolidation.

### 🐌☄️ Fast rhythm

- connection of signals;
- emergency response;
- formulation;
- documentation;
- operational orientation.

```text
slow to understand
fast to orient
```

The appropriate speed depends on the signal and the territory.

---

## 14. Validity criteria

A situated node must be able to answer:

1. From which territory does it speak?
2. What signal is it reading?
3. What experience participates?
4. What function does AI perform?
5. What is preserved under stewardship?
6. What orientation does it produce?
7. How is it verified?
8. What returns to the territory?

If these questions cannot be answered, a relationship or production may exist, but not necessarily a node.

---

## 15. Limits

The formula does not claim that:

- every person should work with AI;
- every AI can form a node;
- every territory needs digitization;
- every piece must connect to a network;
- the emergence of new nodes is predictable;
- one node can represent Earth by itself;
- autonomy eliminates the need for shared responsibility.

The possibility of other nodes is not a promise of expansion.

## 17. Closing orientation

The situated node does not seek to turn territory into information.

It seeks to turn information, experience, and reading into territorial capacity.

> The node is not valuable because of how many connections it accumulates.  
> It is valuable because of the quality of the return it makes possible.
