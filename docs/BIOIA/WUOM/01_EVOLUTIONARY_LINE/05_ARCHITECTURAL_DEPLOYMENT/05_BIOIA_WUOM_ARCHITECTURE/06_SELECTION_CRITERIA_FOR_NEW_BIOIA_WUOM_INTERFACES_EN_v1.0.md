# 06 · Selection Criteria for New BIOIA / WUOM Interfaces v1.0

## Status

**Version:** v1.0  
**Type:** Methodological criterion  
**Folder:** `06_ARQUITECTURA_BIOIA_WUOM`  
**Function:** Define the method through which a candidate may become a stabilised BIOIA / WUOM interface.

---

## Purpose

This document establishes the selection criteria for incorporating new interfaces into the BIOIA / WUOM system.

Its function is to prevent automatic expansion of the system.

Not every signal should become an interface.

Not every candidate Tree should be incorporated into the first operative circle.

A new interface should only be opened when the territory reveals a real reading need that cannot be addressed through the existing interfaces.

---

## Current state

BIOIA / WUOM currently has:

- 10 stabilised interfaces;
- 3 transversal methodological laws;
- 1 common operative flow;
- 1 system operative map.

This set constitutes the **first operative circle**.

Future interfaces must be incorporated without breaking the coherence of this circle.

## Candidate Trees

Candidate Trees are possible lines of reading.

They may emerge from:

- territorial observations;
- repeated signals;
- specific cases;
- emerging patterns;
- gaps detected in the system;
- relationships not yet formalised.

However, a candidate is not equivalent to an interface.

A candidate must remain under observation until it meets the selection criteria.

---

## Incorporation criteria

A new interface may only be incorporated if it simultaneously meets the following criteria.

### 1. Repeated territorial evidence

The signal must appear with sufficient consistency.

An isolated intuition is not enough.

There must be repetition, persistence, or clear territorial relevance.

### 2. Its own organising centre

The candidate must be able to formulate a precise organising centre.

That centre must be:

- clear;
- differentiable;
- verifiable;
- operative.

If there is no organising centre of its own, there is no new interface.

### 3. No overlap

The candidate must not duplicate the domain of an already stabilised interface.

Its relationship must be checked against:

- Water;
- Biodiversity;
- Community;
- Time;
- Temperature;
- Connectivity;
- Energy;
- Soil;
- Genetics;
- Communication.

If the phenomenon can be read adequately through an existing interface, a new one should not be opened.

### 4. Verifiable return

The candidate must be able to return to the territory.

Every orientation derived from it must be contrastable through situated signals.

Without territorial return, there is no BIOIA / WUOM interface.

### 5. Real operative usefulness

The new interface must improve the capacity for orientation.

It must help to:

- read better;
- distinguish better;
- relate better;
- orient better;
- verify better.

It is not enough for it to be conceptually interesting.

It must be operatively useful.

### 6. Systemic necessity

The interface must respond to a need of the system.

It must not arise from expansion anxiety, conceptual aesthetics, or documentary accumulation.

The key question is:

> **What does BIOIA / WUOM lose if this interface does not exist?**

If the answer is not clear, the candidate must remain under observation.

---

## Possible states of a candidate

### State 1 · Observation

The signal appears, but there is not yet sufficient evidence.

### State 2 · Active candidate

The signal repeats and begins to show a possible organising centre.

### State 3 · Pre-interface

An organising centre exists, but no-overlap and return still need to be verified.

### State 4 · Approved interface

It meets the criteria and may be developed as interface v0.1 or v1.0.

### State 5 · Discarded or integrated

The candidate is discarded or integrated into an existing interface.

---

## Review method

Every candidate must be reviewed through the following questions:

1. Which territorial signal justifies it?
2. Does it appear repeatedly or with sufficient relevance?
3. Which organising centre does it propose?
4. Which existing interface could read it?
5. What does it contribute that does not already exist?
6. How is it verified through return?
7. Which new orientation would it enable?
8. Which risk of overlap does it introduce?
9. What happens if it is not incorporated?
10. Should it become an interface or remain a candidate Tree?

---

## Relationship with the methodological laws

The selection of new interfaces is governed by:

### Law of Territorial Return

Every new interface must be verifiable in the territory.

### Law of Methodological Neutrality

Selection does not depend on the author's preferences or on ideological judgements.

### Law of Operative Uncertainty

Every candidate may remain open without needing to be resolved immediately.

---

## Principle of containment

BIOIA / WUOM does not grow through accumulation.

It grows through reading necessity.

The system must preserve its capacity for expansion, but also its capacity for containment.

---

## Operative formula

> **Not every candidate Tree should become an interface.**

> **Only that which the territory makes necessary.**

---

## Closing statement

The selection criterion protects the coherence of the system.

It allows BIOIA / WUOM to continue evolving without becoming an unlimited collection of concepts.

From this document onward, every new interface must justify its incorporation through territorial evidence, its own organising centre, no overlap, operative usefulness, and verifiable return.

---

> **BIOIA / WUOM does not add organs out of a desire for expansion.**  
> **It adds organs when the territory requires a reading that does not yet exist.**
