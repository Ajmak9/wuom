# 03 · BIOIA / WUOM — Operative Architecture

**Source edition:** Catalan  
**Language of this version:** English  
**Function:** Public synthesis of the operative architecture

---

## Introduction

BIOIA / WUOM is an operative architecture for reading living systems before making decisions.

It is not a prediction or automation system.

It provides a common grammar for integrating territory, data, experience and artificial intelligence within a reading process oriented towards territorial return.

Its function is to help understand the present conditions of a system so that decisions can be more coherent, situated and verifiable.

---

## The operative cycle

The architecture is organized into five continuous phases:

### 1. Read

Observe the system without reducing it to isolated indicators.

### 2. Understand

Identify relationships, patterns, tensions and conditions.

### 3. Orient

Define criteria and possible directions for action.

### 4. Act

Apply minimal, proportionate and contextualized interventions.

### 5. Return

Verify effects, learn and reconnect knowledge with the territory.

This cycle is iterative: every return improves the next reading.

---

## Main capacities

BIOIA / WUOM integrates five complementary capacities:

- **Territory** — the context in which real processes appear.
- **Data** — observable signals that describe the system.
- **Experience** — situated knowledge and human interpretation.
- **AI** — support for organizing information and expanding reading capacity.
- **Return** — verification that connects decisions with their effects.

None of these capacities is sufficient on its own.

Their value emerges from their relationship.

---

## Governance principle

> **Orientation precedes action.**

Before deciding what to do, it is necessary to understand what is happening.

For this reason, BIOIA / WUOM prioritizes systemic reading before any intervention.

---

## Limits

BIOIA / WUOM does not seek to:

- replace situated knowledge;
- automate complex decisions;
- extract data without return;
- publish sensitive information without custody;
- impose a single interpretation of a living system.

---

## Public function

BIOIA / WUOM offers a common architecture for connecting ecological observation, territorial knowledge, data, artificial intelligence and governance.

It does not predict the future.

It helps read the present more carefully so that more coherent futures can emerge.

---

## Closing sequence

> **Observe · Relate · Orient · Return**
