## 1. The Core Interface — H/O

H/O is the living interface between:

```text

O = operational structure, form, model, language
```

H/O is not fusion.

H/O is not equivalence.

H/O is crossing.

It is the point where the system touches the world.

Through H/O, situated experience can enter into relation with operational structure without being reduced to it.

```text
H/O = living interface.
```
