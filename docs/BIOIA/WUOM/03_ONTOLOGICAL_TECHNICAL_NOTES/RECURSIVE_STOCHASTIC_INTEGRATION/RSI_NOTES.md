## 4. Conceptual Core

Core sentence:

```text
The system lives because it does not fully coincide with itself.
```

Spanish formulation:

```text
El sistema vive porque no encaja del todo.
```

Reading:

A system that fully coincides with itself becomes static.

A system that maintains a minimal non-coincidence preserves the possibility of movement, friction, reorientation and emission.
