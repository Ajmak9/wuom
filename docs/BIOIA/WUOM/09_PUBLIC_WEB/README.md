## 3. Ecosystem Position

```text
EVA W gives origin to the gaze.
WUOM organizes the reading.
BIOIA verifies it in the territory.
```

The public web makes this architecture navigable.

It does not replace:

- the general gateway at `bioiawuom.org`;
- the territorial gateway at `bioia.cat`;
- the institutional and European gateway at `bioia.eu`;
- the documentary depth and version history preserved on GitHub;
- multilingual documentary navigation on Notion;
- derived operational tools distributed through Gumroad.

It connects these layers and provides a shared public entrance.

---

## 4. Derivation Status

The BIOIA / WUOM Web is a **public derivation**.

It:

- does not modify the core;
- does not replace the root documents;
- does not convert BIOIA into a product;
- does not convert WUOM into a generic method;
- does not collapse the ecosystem into a single channel.

Its function is to organize public access while preserving the identity, limits, custody and territorial return of the ecosystem.
