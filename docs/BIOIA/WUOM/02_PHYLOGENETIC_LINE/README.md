## Purpose

This folder defines the **internal morphodynamic genealogy** of the BIOIA / WUOM organism.

It does **not**:
- redefine the core  
- expand the core  
- open Metabolic Maps  
- activate WUOM  
- generate product material  
- reinterpret the Evolutionary Line  

It only **describes** the internal sequence of conceptual mutations that allow the organism to exist.

---

## Distinction

Evolutionary Line   = architectural deployment of the system
Phylogenetic Line   = morphodynamic mutation of the organism

The Phylogenetic Line does **not** correct the Evolutionary Line.  
It **complements** it from another plane.
