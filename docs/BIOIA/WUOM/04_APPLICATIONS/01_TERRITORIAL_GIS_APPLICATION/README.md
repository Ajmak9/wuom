## Purpose

This folder records the territorial GIS application of **BIOIA / WUOM**.

It explores how BIOIA / WUOM can operate as a situated reading framework for territorial layers, spatial relations, risk patterns, infrastructure, environmental context, and decision-oriented mapping.

This is an applied branch.

It is not the root architecture.

It does not redefine BIOIA.

It does not redefine WUOM.

It does not open metabolism.

It does not activate breath.

It does not activate WUOM.

## Acronyms

**GIS** = **Geographic Information System**

**SIG** = **Sistema de Información Geográfica**

Both terms refer to systems that collect, organize, analyze, and visualize geographically referenced information linked to territory.

In this folder:

```text
GIS = English term
SIG = Spanish term
```
