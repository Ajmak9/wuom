## Purpose

This document records a derived territorial GIS subcase of **BIOIA / WUOM** focused on land use change analysis through spatial data, temporal comparison, and hydrological impact indicators.

The observed reference is an API capable of comparing land use between two time periods and estimating effects on runoff, infiltration, vegetation cover, hydrological response, and territorial impact.

This is an applied subcase.

It is not the root architecture.

It does not redefine BIOIA.

It does not redefine WUOM.

It does not open metabolism.

It does not activate breath.

It does not activate WUOM.

## BIOIA / WUOM Reading

### GIS reads layers

GIS organizes territorial information into spatial layers:

```text

vegetation
infrastructure

```

### The API queries change

The API converts temporal comparison into operational indicators:

```text
what changed
where it changed
how much it changed
what impact it produced
```

### WUOM reads relations

WUOM does not read isolated layers.

It reads relations between:

```text

runoff
vegetation
infiltration
slope
infrastructure
risk
```
