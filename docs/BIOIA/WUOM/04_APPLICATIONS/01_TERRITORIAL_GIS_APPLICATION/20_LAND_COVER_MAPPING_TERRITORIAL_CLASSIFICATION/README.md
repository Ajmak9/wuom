## Purpose

This folder documents **Land Cover Mapping and Territorial Classification** as a derived territorial GIS application inside BIOIA / WUOM.

Its function is to describe how the visible surface of the territory can be classified, mapped and interpreted as part of a situated territorial reading.

This is not a foundational document.
It does not redefine BIOIA / WUOM.
It does not open respiration.
It does not activate WUOM as a general phase.

## Operational Definition

Land cover mapping identifies what physically covers the surface of a territory.

It can classify areas such as:

```text
forest
grassland
agriculture
bare soil
water
wetlands
urban areas
roads
infrastructure
shrubland
burned areas
mixed vegetation
```

Land cover is not the same as land use.

Land cover describes what is present on the surface.
Land use describes how that surface is used, managed or occupied.

---

## BIOIA / WUOM Reading

```text
BIOIA = living territorial field

Land cover = visible surface structure of the field

GIS = system that organizes classified territorial layers

WUOM = apparatus that reads relations between cover, use, change, risk and orientation
```

This module does not reduce territory to categories.

It uses classification to make surface relations readable.

---

## Classification Logic

Land cover mapping usually follows a sequence:

```text
territory
↓
observation / imagery
↓
surface classes
↓
classification
↓
GIS layer
↓
validation
↓
change comparison
↓
WUOM relational reading
↓
territorial orientation
```

Classification is not the final reading.

It prepares the territory for relational interpretation.

## What This Layer Corrects

This layer avoids reducing classification to a visual legend.

```text
without validation
→ classification may become decorative

without temporal comparison
→ change remains hidden

without WUOM reading
→ categories remain isolated

without BIOIA
→ the surface loses its living field
```

A land cover map becomes useful when its categories are read as relations.

## Operational Rule

Before using land cover classification for territorial decisions:

```text
verify source imagery
verify spatial resolution
verify classification method
check class definitions
validate with field evidence
compare with previous states
connect classes to territorial questions
```

The map must not only classify.

It must help understand what the surface is doing.
