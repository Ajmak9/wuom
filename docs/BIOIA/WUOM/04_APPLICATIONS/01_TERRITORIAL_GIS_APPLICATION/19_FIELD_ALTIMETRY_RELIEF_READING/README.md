## Purpose

This folder documents **Field Altimetry and Relief Reading** as a derived territorial GIS application inside BIOIA / WUOM.

Its function is to describe how elevation, slope, relief and field measurements help read the territorial form before interpreting risk, access, visibility, water flow or land use.

This is not a foundational document.
It does not redefine BIOIA / WUOM.
It does not open respiration.
It does not activate WUOM as a general phase.

## Operational Definition

Field altimetry and relief reading connects direct territorial observation with elevation-based spatial structure.

It can involve:

```text
elevation
slope
relief
contour lines
altitude differences
terrain breaks
high points
low points
drainage direction
access gradients
visible ridges
valleys
field measurements
digital elevation models
```

Relief is not only physical surface.

It conditions movement, water, visibility, risk, access and occupation.

## BIOIA / WUOM Reading

```text
BIOIA = living territorial field

Altimetry = elevation structure of the field

Relief = visible and measurable form of terrain

```

The module does not reduce territory to height values.

It reads elevation as territorial structure.

```text
territory
```

## What This Layer Corrects

This layer avoids reducing elevation to a simple number.

```text
without relief reading
→ elevation remains isolated

without field context
→ slope loses territorial meaning

without WUOM reading
→ altimetry becomes technical data without orientation
```

Relief must be read as a relation, not as an isolated measurement.

---

## Operational Rule

Before using elevation or relief data for territorial decisions:

```text
verify elevation source
verify coordinate reference system
verify vertical reference
check resolution
compare with field observation
read slope and contour logic
connect relief to water, access, risk and visibility
```

Altitude is not enough.

The important question is what the terrain is doing.
