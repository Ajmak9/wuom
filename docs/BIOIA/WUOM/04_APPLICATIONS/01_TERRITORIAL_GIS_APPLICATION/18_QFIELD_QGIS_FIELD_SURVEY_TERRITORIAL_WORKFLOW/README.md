## Purpose

This folder documents **QField + QGIS Field Survey Territorial Workflow** as a derived territorial GIS application inside BIOIA / WUOM.

Its function is to describe how field observation, mobile data collection and GIS organization can form a situated territorial workflow.

This is not a foundational document.
It does not redefine BIOIA / WUOM.
It does not open respiration.
It does not activate WUOM as a general phase.

## Operational Definition

A field survey territorial workflow connects direct observation with spatial data organization.

It can involve:

```text
field observation
mobile data collection
GPS location
photos
attributes
field notes
geometries
QField
QGIS
layer validation
territorial interpretation
```

The field is not reduced to data.

Data becomes useful when it remains connected to place, observation and context.

---

## BIOIA / WUOM Reading

```text
BIOIA = living territorial field

QField = field capture interface

QGIS = spatial organization and verification environment

WUOM = apparatus that reads relations between field observation, layer structure and territorial meaning
```

The workflow does not replace situated observation.

It records, organizes and prepares it for relational reading.

---

## Field Logic

The workflow moves through a basic sequence:

```text
territory
↓
field observation
↓
mobile capture
↓
geometry and attributes
↓
QGIS verification
↓
layer organization
↓
WUOM relational reading
↓
territorial orientation
```

A field survey is not only technical capture.

It is a contact point between territory and system.

## What This Layer Corrects

This layer avoids reducing GIS to office-based mapping.

It also avoids reducing fieldwork to unstructured observation.

```text
without field workflow
→ observation remains isolated

without GIS verification
→ collected data may lose structure

without WUOM reading
→ data remains operational but not relational
```

A field workflow becomes valuable when field observation, GIS structure and territorial interpretation remain connected.

---

## Operational Rule

Before using field data for territorial decisions:

```text
verify location accuracy
verify geometry type
check attributes
review photos and notes
confirm coordinate system
validate field consistency
connect the data to the territorial question
```

Field data must remain situated.

A point without context is only a coordinate.

A point with context becomes territorial evidence.
