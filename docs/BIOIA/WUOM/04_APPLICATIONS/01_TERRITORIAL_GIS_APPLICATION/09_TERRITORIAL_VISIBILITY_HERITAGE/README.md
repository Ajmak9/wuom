## Purpose

This folder documents **Territorial Visibility and Heritage** as a derived territorial GIS application inside BIOIA / WUOM.

Its function is to describe how territory can be read not only through layers, measurements, land use or risk, but also through visual relations:

```text
what is visible
what remains hidden
from where the territory is observed
which places are visually connected
which positions dominate the landscape
which heritage elements organize territorial perception
```

This is not a foundational document.
It does not redefine BIOIA / WUOM.
It does not open respiration.
It does not activate WUOM as a general phase.

## Operational Definition

Territorial visibility studies visual relations between observation points, elevation, relief, routes, settlements, monuments and heritage structures.

It can rely on:

```text
digital elevation models
relief
observer height
distance
lines of sight
viewsheds
intervisibility
natural or built obstacles
```

Its core question is:

```text
What parts of the territory are visible from a given position?
```

And also:

```text
Which places can see each other?
```

---

## BIOIA / WUOM Reading

```text
BIOIA = territorial-cultural field where visibility has meaning

GIS = system that models relief, elevation and lines of sight

WUOM = apparatus that reads visual relations, positions and spatial tensions

Heritage = situated memory within the landscape
```

Visibility is not interpreted as simple geometry.

It is interpreted as a relation between landscape, memory, power, orientation and occupation.

## Relation to Archaeology and Heritage

In archaeology and heritage studies, visibility helps to understand:

```text
why a site was located in a specific place
which areas it could visually control
which other sites were visually connected
which routes or passes were visible
which landscape elements had symbolic value
how spatial occupation was organized
```

The location of a site is not only geographic.

It can also be visual, cultural and strategic.

## Operational Rule

Before acting on a heritage landscape, its visual relations should be read.

```text
It is not enough to know where a site is.
It is necessary to know what it sees, what it connects and what position it occupies within the visual field of the territory.
```

Visibility can reveal relations that a conventional layer does not show.
