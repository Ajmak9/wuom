## Purpose

This folder records **Topographic Reading** as a derived territorial GIS application within BIOIA / WUOM.

It does not redefine BIOIA.

It does not redefine WUOM.

It does not modify the root architecture.

It does not open metabolism.

It does not activate breath.

It does not activate WUOM as a general phase.

Its function is to document basic cartographic literacy as a necessary condition for situated territorial reading.

---

## Operational Position

Topographic reading is not advanced modelling.

It is not prediction.

It is not a complete GIS workflow.

It is the minimum layer of territorial literacy required before spatial layers can be interpreted meaningfully.

```text
Topographic map
→ territorial layers
→ GIS integration
→ WUOM relational reading
→ territorial orientation
→ situated decision
```

---

## Basic Map Elements

A topographic map organizes territorial information through basic reading components:

```text
map title
scale
north arrow
legend / key
contour lines
spot heights
benchmarks
relief features
grid system
coordinates
projection and coordinate system
data source
contour interval
cartographic symbols
```

These elements make it possible to locate, measure, compare and understand spatial relations.

## BIOIA / WUOM Reading

```text
Topographic map = territorial literacy
GIS = layer integration
WUOM = relational reading
BIOIA = field where that reading makes sense
```

The map is not only an image.

It is an interface for reading territory.

It translates relief, water, paths, settlements, vegetation, elevation, symbols and spatial references into a legible field.
