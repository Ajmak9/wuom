## Purpose

This folder documents **Google Earth Engine and Territorial Automation** as a derived territorial GIS application inside BIOIA / WUOM.

Its function is to describe how large-scale geospatial processing, scripting, temporal analysis and automated workflows can extend territorial reading without replacing situated interpretation.

This is not a foundational document.
It does not redefine BIOIA / WUOM.
It does not open respiration.
It does not activate WUOM as a general phase.

## Operational Definition

Google Earth Engine can be understood here as an infrastructure for territorial processing at scale.

It enables work with:

```text id="f8c3m7"
satellite imagery
time series
vegetation indices
surface temperature
precipitation
land cover
territorial change
environmental events
raster data
multi-temporal collections
```

Its value is not only map visualization.

Its value is the ability to automate repeatable readings over large and changing territories.

## Technical Risk

Automation can produce false precision if it is not oriented.

It requires verification of:

```text id="ixhf0a"
data source
spatial resolution
temporal resolution
preprocessing quality
filtering criteria
analysis scale
territorial meaning of the output
```

Processing more does not automatically mean understanding better.

Understanding depends on the relation between data, territory and question.

---

## Operational Rule

Before automating a territorial analysis:

```text id="sa4n0m"
define the question
delimit the territory
verify the data
establish the scale
document the script
validate the result
interpret with context
```

Automation must serve reading.

It must not replace it.
