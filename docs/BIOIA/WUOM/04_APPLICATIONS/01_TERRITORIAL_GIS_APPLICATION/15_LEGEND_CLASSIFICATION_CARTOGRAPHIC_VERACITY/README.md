## Purpose

This folder documents **Legend, Classification and Cartographic Veracity** as a derived Territorial GIS application inside BIOIA / WUOM.

Its function is to describe how a map legend, a classification method and a visual scale can orient territorial reading correctly or silently distort it.

A legend is not an aesthetic detail.

A legend is an analytical decision.

This is not a foundational document.
It does not redefine BIOIA / WUOM.
It does not open respiration.

## Operational Definition

A cartographic legend organizes the visual translation of data.

It can represent:

```text
categories
ranges
intensities
classes
intervals
thresholds
growth
loss
risk
presence
absence
density
territorial variation
```

Its function is not only to explain colors or symbols.

Its function is to sustain a veracious reading of the represented phenomenon.

## Classification by Phenomenon

Not every phenomenon should be classified in the same way.

A single scale can distort different phenomena.

Examples:

```text
external migration
internal migration
urban growth
vegetation cover loss
hydrological risk
social vulnerability
land use change
```

Each variable may require its own classification logic.

Classification must respond to the behavior of the phenomenon, not to design convenience.

---

## Common Legend vs Situated Legend

A common legend can be useful when datasets are comparable.

But it can become false when it forces different phenomena into the same scale.

```text
Common legend:
supports comparison
may simplify reading
may hide internal differences
may force homogeneous interpretation

Situated legend:
responds to the phenomenon
respects data distribution
shows relevant thresholds
avoids visual distortion
```

The question is not only:

```text
Which legend looks clearer?
```

The correct question is:

```text
Which legend best represents the actual behavior of the phenomenon?
```

---

## Risk of Visual Scale

Color can make a difference appear larger or smaller than it is.

A poorly applied color scale can:

```text
exaggerate a small difference
hide an important difference
turn continuity into rupture
turn rupture into continuity
homogenize different phenomena
generate false alarm
generate false calm
```

Cartographic veracity depends both on the data and on its representation.

```text

```

## Operational Rule

Before accepting a cartographic legend:

```text
verify the represented phenomenon
verify data distribution
verify classification method
verify thresholds
verify color scale
verify whether comparison is valid
verify whether the legend hides or exaggerates differences
verify whether visual reading matches data behavior
```

The legend must be reviewed as rigorously as the data.
