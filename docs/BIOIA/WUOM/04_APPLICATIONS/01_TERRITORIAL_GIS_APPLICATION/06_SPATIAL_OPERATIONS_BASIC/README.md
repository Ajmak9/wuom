## Purpose

This folder documents **Basic Spatial Operations** as a derived territorial GIS application inside BIOIA / WUOM.

Its function is to describe the minimal spatial operations that allow territorial layers to become readable relations.

This is not a foundational document.
It does not redefine BIOIA / WUOM.
It does not open respiration.
It does not activate WUOM as a general phase.

## Operational Definition

A spatial operation is an action that works with geographic entities and their relations.

It can operate on:

```text
points
lines
polygons
areas
networks
influence zones
territories
coverages
routes
patterns
```

Its function is to make spatial reading operational.

Without spatial operations, layers remain isolated.

---

## Main Operations

Basic territorial reading may involve operations such as:

```text
point
polygon
radius / buffer
drive time
geocoding
spatial join
overlap
coverage gap
hotspot
aggregation
split territory
union territory
snapshot
network coverage
```

Each operation answers a different territorial question.

---

## Operational Questions

```text
Point:
Where does something occur?

Polygon:
What area is delimited?

Buffer:
What exists around a place?

Drive time:
What can be reached within a given time?

Geocoding:
Where is an address located?

Spatial join:
What data connect through location?

Overlap:
What territories intersect?

Coverage gap:
Where is service, access or presence missing?

Hotspot:
Where is intensity concentrated?

Aggregation:
What values appear when an area is summarized?

Split territory:
How is a zone divided?

Union territory:
How are related areas combined?

Snapshot:
What changed between two moments?

Network coverage:
What areas are reached by an infrastructure or service?
```

## BIOIA / WUOM Reading

```text
BIOIA = territorial field where operations make sense

GIS = system that executes spatial operations

```

A spatial operation is not the final reading.

It is a mediation.

It allows the system to move from isolated layer to territorial relation.

## What This Layer Corrects

This layer prevents GIS from being reduced to simple visualization.

A map can show layers.

A spatial operation allows the system to ask:

```text
what connects
what intersects
what is missing
what concentrates
what moves
what changes
what is covered
what remains outside
```

Without operation, there is image.

With operation, reading appears.

---

## Relation to Risk

Basic spatial operations support territorial risk reading.

Examples:

```text
buffer → proximity to threat
overlay → intersection between threat and vulnerability
hotspot → concentration of events
coverage gap → areas without service or protection
network coverage → emergency accessibility
aggregation → summary by territorial unit
```

Risk appears when several layers and operations are read together.

---

## Operational Rule

Before interpreting a spatial result:

```text
verify the operation used
verify the layers involved
verify the scale
verify the spatial reference
verify the purpose of the question
verify whether the output answers the territorial problem
```

Not every operation produces orientation.

It only does so when it is properly situated.
