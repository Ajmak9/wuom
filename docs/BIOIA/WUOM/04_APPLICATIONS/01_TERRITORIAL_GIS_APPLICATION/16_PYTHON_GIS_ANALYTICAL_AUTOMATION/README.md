## Purpose

This folder documents **Python + GIS and Analytical Automation** as a derived Territorial GIS application inside BIOIA / WUOM.

Its function is to describe how programming can extend, automate and make territorial analysis processes reproducible.

Python does not replace territorial reading.
Python does not replace criteria.
Python does not decide.

It processes, transforms, repeats and verifies operations over spatial data.

This is not a foundational document.
It does not redefine BIOIA / WUOM.
It does not open respiration.
It does not activate WUOM as a general phase.

## Technical Risks

Python + GIS can also produce errors when used without territorial criteria.

Common risks include:

```text
automating errors
processing misprojected data
using invalid geometries
losing territorial context
confusing speed with quality
creating results without visual review
applying scripts without understanding scale
mixing incompatible layers
generating false precision
```

Automating an error does not correct it.

It multiplies it.
