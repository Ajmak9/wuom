## Purpose

This folder records **Geospatial Risk Reading** as a derived territorial GIS application within BIOIA / WUOM.

It does not redefine BIOIA.

It does not redefine WUOM.

It does not modify the root architecture.

It does not open metabolism.

It does not activate breath.

It does not activate WUOM as a general phase.

Its function is to read territorial risk as a relation between physical layers, human activity, vulnerability, exposure, local memory and situated decision-making.

---

## Operational Position

Geospatial risk reading is not only prediction.

It is not only visualization.

It is not a standalone GIS model.

It is a situated reading of territorial tensions.

```text
territory
→ risk layers

→ WUOM relational reading
→ territorial risk synthesis
→ situated orientation
```

## WUOM Relational Reading

WUOM operates as the relational reading apparatus.

It is not a predictive model.

It is not a GIS tool.

It is not another data layer.

It reads interdependencies between layers.

WUOM reads:

```text
networks
thresholds
proximities
vulnerabilities
correlations
dependencies
critical points
cumulative effects
```

### Networks

How elements connect, influence and amplify one another.

### Thresholds

Where the system changes state or collapses.

### Proximities

What is too close to what should remain distant.

### Vulnerabilities

Where the territorial fabric is weakest.

### Correlations

Which factors combine to produce damage.

```text
WUOM reads relations.
```
