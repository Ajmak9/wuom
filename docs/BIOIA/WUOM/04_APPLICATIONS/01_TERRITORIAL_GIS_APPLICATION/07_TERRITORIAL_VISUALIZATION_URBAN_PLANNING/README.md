## Purpose

This folder documents **Territorial Visualization and Urban Planning** as a derived territorial GIS application inside BIOIA / WUOM.

Its function is to describe how territorial visualization transforms spatial layers into readable relations that can support urban, environmental, social and spatial decisions.

This is not a foundational document.
It does not redefine BIOIA / WUOM.
It does not open respiration.
It does not activate WUOM as a general phase.

## Operational Definition

Territorial visualization is not decoration.

It is the process of making territorial relations visible so they can be understood, compared and used for situated decision-making.

It can integrate layers such as:

```text
land use
mobility
infrastructure
risks
facilities
green areas
urban density
administrative limits
urban growth
service coverage
ecological structure
```

When these layers are visualized together, they stop being isolated data and begin to reveal patterns, tensions, opportunities and conflicts.

---

## BIOIA / WUOM Reading

```text
BIOIA = living territorial field

GIS = system that organizes and represents spatial layers

WUOM = apparatus that reads relations between layers

Visualization = interface that makes relations legible

Planning = situated decision over the territory
```

Visualization does not replace reading.

It prepares reading.
