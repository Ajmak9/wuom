## Overview

This repository contains the English public documentation of the first ten **BIOIA / WUOM interfaces**.

Each interface is a situated reading organ with:

- its own organizing center;
- a defined operational scope;
- explicit limits;
- relationships with the other interfaces;
- verification through territorial return.

The interfaces do not divide the territory into isolated sectors. They provide complementary readings of processes that remain connected within the same living system.

> **One territory. Multiple reading organs. Shared orientation. Verifiable return.**

## Core Sequence

```text
Observe
→ Interpret
→ Relate
→ Orient

```

BIOIA / WUOM does not replace situated experience, professional knowledge, human deliberation, or territorial verification.

AI amplifies the reading.

## How to Read the Collection

The interfaces may be read individually, but their full meaning appears through relation.

A useful sequence is:

1. Identify the territorial signal.
2. Open the interface most directly related to that signal.
3. Read the relationships with the other interfaces.
4. Build a situated orientation without collapsing the domains.
5. Return the orientation to the territory for verification.

Example:

```text
Thermal signal
→ Temperature
→ Water + Soil + Biodiversity + Community + Time + Energy + Connectivity
→ situated orientation
→ territorial return
```
