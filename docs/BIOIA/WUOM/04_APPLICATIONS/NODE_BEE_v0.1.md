# Node Bee · BIOIA / WUOM

**Node Bee** is a public BIOIA application that uses the bee as an **operational metaphor** for understanding relationships between territory, data, human experience, artificial intelligence, and territorial return.

It is **not** a technological beehive, a drone network, or a robotic system.

The objective is to improve territorial interpretation while respecting ecological integrity, scientific verification, and ethical governance.

## Ethical Note

The bee is used exclusively as an **operational metaphor**.

This project does **not** promote:

* Robotic bees
* Drone surveillance
* Automated ecological control
* Monitoring of real beehives
* Collection of sensitive ecological locations

The ecological role of real pollinators always has priority.
