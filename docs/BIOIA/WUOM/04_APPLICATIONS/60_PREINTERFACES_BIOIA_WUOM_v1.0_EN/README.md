## Overview

This repository contains the English public documentation of the first three **BIOIA / WUOM pre-interfaces**:

1. **Fire**
2. **Air**
3. **Darkness**

A pre-interface is not a consolidated interface and is not merely an unfinished draft.

It is a **territorial reading organ under advanced methodological evaluation**. It has already surpassed the nursery stage, but it has not yet entered the first operational circle as a stable interface.

> **A pre-interface remains open until repeated territorial returns confirm autonomy, usefulness and operational stability.**

---

## Architectural Position

BIOIA / WUOM currently distinguishes three levels:

```text
Candidate tree
(in the nursery)
        ↓
Pre-interface
(advanced evaluation)
        ↓
Consolidated interface
(stable operational organ)
```

The pre-interfaces form a **second circle in formation**.

They do not replace the ten consolidated interfaces. They read conditions that emerge when several interfaces converge and when the territory reveals a distinct organizing center.

## Core Distinctions

### Fire

Fire is not read only as an event, heat source or emergency.

It is read as a **threshold of territorial transformation** that appears when multiple conditions converge.

### Air

Air is not empty and is not identical to wind.

```text
Air  = the medium
Wind = movement of the medium
```

Air enables respiration, circulation, exchange, exposure and relation.

### Darkness

Darkness is not merely the absence of light and is not identical to nighttime.

```text
Time     = rhythm
Darkness = ecological condition
```

Darkness enables biological rhythms, nocturnal movement, refuge, rest and ecological continuity.

## Relationship with the Consolidated Interfaces

The pre-interfaces are relational.

They do not operate outside the first circle. They read how existing interfaces converge around a territorial condition.

The ten consolidated interfaces are:

1. Genetics
2. Communication
3. Water
4. Biodiversity
5. Community
6. Time
7. Temperature
8. Connectivity
9. Energy
10. Soil

Example:

```text
Fire
→ Temperature + Water + Soil + Biodiversity
→ Community + Energy + Connectivity + Time
→ threshold of transformation
→ territorial return
```

The same principle applies to Air and Darkness.

## Methodological Sequence

```text
Candidate signal
→ observation
→ relational reading
→ provisional organizing center
→ first territorial return
→ advanced evaluation
→ repeated cases
→ methodological decision
```

A pre-interface may:

- remain active;
- return to the nursery;
- integrate into another interface;
- be discarded;
- or advance toward consolidation.

No transition is automatic.

---

## Validation Criteria

A pre-interface may advance only if it demonstrates:

- a distinct organizing center;
- methodological autonomy;
- limited redundancy with existing interfaces;
- usefulness in real cases;
- applicability across different territories;
- continued territorial verification;
- capacity to improve orientation;
- operational stability over time.

> **Conceptual strength is not sufficient.  
> Territorial return must confirm the organ.**

## Limits

This repository is not:

- a technical standard;
- a closed methodology;
- an automated decision system;
- an emergency-response protocol;
- a substitute for fieldwork;
- a substitute for scientific, ecological, legal, engineering, health or administrative expertise;
- evidence that any pre-interface has already become a consolidated interface.

The documents organize observation, relation and orientation. Final responsibility remains with the people, communities, institutions and professionals involved in each case.
