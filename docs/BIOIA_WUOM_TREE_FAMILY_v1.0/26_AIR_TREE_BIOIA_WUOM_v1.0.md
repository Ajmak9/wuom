# Initial Hypothesis

Air could represent a specific dimension of territorial habitability because it does not act only as a physical medium.

It acts as flow, mixture, transport, respiration, dispersion, accumulation, and signal.

Air quality is one of its main readings, but it does not exhaust the tree.
