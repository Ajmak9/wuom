# BIOIA / WUOM Tree Family v1.0

## Overview

The BIOIA / WUOM Tree Family is a collection of conceptual trees that organize the ecosystem through a common structural grammar.

Each tree focuses on a specific function while preserving the same conceptual identity, operational principles, and verification through practice.

This repository presents the English branch of the Tree Family.

---

## Core Principle

One ecosystem.  
One shared grammar.  
Many specialized trees.

The trunk remains stable.  
The branches adapt to their purpose, language, and territory.

## Tree–Document Relationship

The tree is the primary conceptual unit.

The document records, explains, and stabilizes its reading.

A tree may temporarily exist without a complete document while it remains under development.

A document without an autonomous tree belongs to the architectural, methodological, genealogical, or editorial support layer and is not counted as a Tree Family entry.

## Language and Territory

This repository represents the English branch of the BIOIA / WUOM ecosystem.

It is not a literal translation of the Spanish version.

Each language constitutes a specific branch rooted in its own cultural and territorial context while preserving the same structural invariants.

## BIOIA / WUOM

BIOIA enables situated reading.

WUOM (Universal Operating Model) provides the operational grammar.

Together they organize living knowledge through territory, experience, intelligence, and verifiable return.
