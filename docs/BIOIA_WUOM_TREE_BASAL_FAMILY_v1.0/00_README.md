# BIOIA / WUOM
## Basal Family v1.0

The Basal Family gathers the first foundational reading organs of BIOIA / WUOM.

It does not describe isolated objects.
It organizes situated readings of the territory.

Each organ contributes a different perspective:

- 🌱 Soil Tree
- 🌍 Territory Tree
- 🚁 Drone Tree
- 💧 Water Tree

Together they form a common reading grammar.

BIOIA integrates the readings.
WUOM organizes the orientation.
The territory verifies the return.

---

### Principles

- Relationships precede the network.
- Territory precedes orientation.
- Elements describe; relationships sustain.
- Productivity is not the same as autonomy.
- Time is also an ecological cost.
- The grammar is common; the reading is territorial.
- The network accompanies; it does not replace.

### Purpose

The Basal Family is not a monitoring system.

It is a framework for reading ecological relationships before intervention.

Observation precedes orientation.
Orientation precedes action.
Return verifies learning.
